# ODK Site

Marketing and documentation site for the Omni Development Kit

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE.md)

</div>

## Overview

ODK Site is the public-facing site for the [Omni Development Kit](https://odk.omni.dev), built with [TanStack Start](https://tanstack.com/start) and React.

## Prerequisites

- [Bun](https://bun.sh) 1.3+

## Development

```bash
bun i
bun dev
```

## Building

```bash
bun build
bun start
```
